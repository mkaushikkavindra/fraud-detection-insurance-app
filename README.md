# fraud-detection-insurance-app
Assigns a fraud risk score to a given input claim, which shows the possibility of fraud.

This is a multi-page Streamlit application designed to calculate the fraud risk score for car insurance claims in real-time. It leverages a powerful **Ensemble Machine Learning** model combined with **Natural Language Processing (NLP)** for comprehensive risk assessment.

The application allows users to submit single claims via a detailed form or process multiple claims efficiently via a batch CSV file upload.

## Features

* **Ensemble Scoring:** Utilizes three distinct machine learning models (Gradient Boosting Classifier, Random Forest, and Logistic Regression) with a **Max-Score Selection policy** to provide the most conservative and secure fraud risk score.
* **NLP Text Analysis:** Calculates a **Text Suspicion Score** by analyzing the claim description using a Sentence Transformer model to detect suspicious language patterns.
* **Two Input Modes:**
    * **Single Claim Entry:** Detailed web form for instant analysis of one claim.
    * **Batch File Upload:** Upload a CSV file containing multiple claims for bulk processing and downloadable results.
* **Clear Decisioning:** Provides a direct recommended action based on the final risk score: **Approve Automatically**, **Manual Review Required**, or **Flagged as Potential Fraud**.
* **Secure Access:** Includes a basic login system using `st.session_state` and page switching to restrict access to authenticated users.

## Installation and Setup

### 1. Prerequisites

Ensure you have Python 3.9+ installed.

### 2. Clone the Repository

```bash
git clone [https://github.com/your-username/fraud-detection-insurance-app.git](https://github.com/your-username/fraud-detection-insurance-app.git)
cd fraud-detection-insurance-app
```

### 3. Install Dependencies
All necessary libraries are listed in requirements.txt.

```bash
pip install -r requirements.txt
```

Note: Due to the use of sentence-transformers, this installation may be slightly longer as it includes large packages like torch and tensorflow.

### 4. Run the Application
The application's main entry point is Login.py.

```bash
streamlit run Login.py
```

## Core Logic: How Scoring Works

The fraud risk score is calculated by the functions in fraudriskscore_final.py:

### 1. Feature Preparation
The claim data is processed to create essential engineered features (ratios, flags, time differences) before being passed to the models.

### 2. Model Prediction
Each claim is independently scored by the three persisted models (RFC, GBC, LR), each providing a probability of fraud (0.0 to 1.0).

### 3. Final Decision
The fraudriskscore_ensemble function implements the Max-Score Selection strategy: the final, single Fraud Risk Score displayed to the user is the highest probability generated by any of the three models. This ensures the application prioritizes detection and high recall. The associated Risk Level and Decision are determined based on the specific thresholds configured for the model that returned the highest score.
